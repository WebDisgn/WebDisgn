Soy un **programador full stack** con experiencia en **Laravel**, **JavaScript**, **Flutter**, **Node.js**, y mucho más. Mi pasión es crear soluciones innovadoras para problemas reales, desde aplicaciones web hasta sistemas móviles.

Me especializo en el desarrollo de **soluciones personalizadas** que mejoran la productividad y experiencia del usuario. ¡Si estás buscando un desarrollador con experiencia y enfoque en resultados, has llegado al lugar correcto!

## 📌 Proyectos Destacados

- **[Sistema de Gestión de Inventarios](enlace-al-repo)**: Un sistema completo de gestión de inventarios desarrollado con **Laravel** y **MySQL**. Este proyecto cubre todas las necesidades de un sistema de inventarios moderno: gestión de productos, proveedores y ventas.
  
- **[Reconocimiento Facial con FaceAPI.js](enlace-al-repo)**: Implementación de un sistema de **autenticación biométrica** usando **FaceAPI.js**. Este proyecto demuestra cómo utilizar técnicas avanzadas de **reconocimiento facial** para crear una capa adicional de seguridad en aplicaciones web.

- **[Aplicación Pokémon (Flutter)](enlace-al-repo)**: Una app móvil interactiva para ver información de **Pokémon** utilizando la **Pokémon API**. La app permite ver detalles de cada Pokémon y realizar búsquedas por nombre, tipo y más.
